# Nikunj Kothari（FPV Ventures 合伙人）

FPV Ventures 合伙人，前 founder/operator（曾在 Meter），转型 VC 约两年；刊中言论密度高，主线是早期市场结构判断（seed-A 断层、并购潮、估值游戏）+ 给创始人的可执行建议，副线是自己重度上手 Claude Code 做 side project 和个人工具。

## 立场与主张

### 留存 > 势头/曝光（最稳定的主线）
- 尽调先翻 changelog：高调发布的公司常连续数周无产品更新，根源是创始人把精力错配到传播和融资；建议把精力换到付费客户上，「VC 会跟着来」（[2026-04-08-changelog-check]）
- 势头从来不是护城河：2023-2025 这批公司靠发布视频和分发换来融资，但忽视留存，钱烧完开始买单；预计 acquihire 节奏会比以往快得多（[2026-05-05-nikunj-momentum-not-a-moat-retention]）。与 4 月 changelog 论是同一判断的两次表述，立场一致无变化。

### 市场结构：seed-A 断层与并购潮
- 并购热度照此下去会盖过融资公告，主因：seed-A 断层恶化、2021 vintage zombiecorn 清算、大厂吸人才、公开市场疲软、扁平组织催生更多创业者；「创始人很多，企业家很少」（[2026-04-24-nikunj-ma-wave]）
- seed-A gap 也推高了融资门槛：单点叙事融不到资，要在 why now/融资/分发/市场/产品/收入六要素上有难复制的组合独特性（[2026-06-03-nikunj-kothari-fundraising-bar]）。注意：这是同一个 gap 论据在两个方向上的使用（解释并购潮 + 解释融资门槛），自洽。

### 对 VC 同行的批评 / 给创始人的避坑建议
- 批评只追 markup 的 VC：半年内从「我的 conviction 值低估值」翻成「估值越高越好、给 LP 看 marks」；建议选传教士不选雇佣兵，背调将进 cap table 的具体那个人（[2026-04-12-nikunj-vc-backchannel]）
- 批评「大模型厂会收购兜底」式出手：连问五个为什么后 GP 的真实理由是下行有保底；他不认为这种打法历史上做出过 5-10 倍基金，猜测激励已转向 AUM 最大化（自认有牢骚成分，但五问对话是一手经历）（[2026-05-03-nikunj-downside-capping]）
- 转型 VC 两年 11 条心得：conviction 不在 data room 里；对的 deal 错的时机仍是错的 deal；慢拒绝比快拒绝糟；好 founder 能把一个问题正反两面讲透（[2026-04-11-nikunj-vc-lessons]）

### 员工股权与独角兽估值
- 分层估值下加入新晋独角兽的「三重打击」：行权价常达领投优先股价两倍多、409A/提前行权成本高、纸面薪酬被估值灌水；建议入职前用 Claude/ChatGPT 做退出测算、像投资人一样尽调；同时收敛——不是所有独角兽都一样（[2026-05-18-nikunj-kothari-unicorn-equity-triple-whammy]）

### vibe coding：边界论 + 自己重度实践
- 边界论：不否认简单工作流会被 vibe code 掉，但质量、深度、好系统仍要时间——「You can't vibe code lessons」（[2026-04-15-nikunj-vibe-code-lessons]）
- 实践上是重度用户，且方法论输出密集：开源 LLMwiki 个人维基（Opus 4.5 vibe code，[2026-04-09-llmwiki]）；第一个付费 side project 购房报告工具，按成本价卖、半价码换反馈（[2026-05-02-nikunj-paid-side-project]）；「模型执行单位」估工指令（[2026-05-10-nikunj-model-execution-units]）；用 Claude Code 嗅探网络请求逆向 API，并预测网站将需要 headless 化和 tools.txt（[2026-05-25-nikunj-reverse-engineer-apis-claude-code]）；用 200+ 份 Granola 会议记录搭 Nock skill，用真实对话做对照式 eval 打磨到「像他本人」（[2026-06-05-nikunj-nock-skill-from-meeting-notes]）
- 两条线不矛盾：他用 AI 压低执行成本，但坚持判断/经验/打磨没法 vibe code——这是他「留存 > 势头」主线在工具层的延伸。
- 6-27 给 taste 加一层细分（对前一条的细化，非反转）：taste 是靠下场反复迭代 + 主动打破模式练出来的、可习得的本事，所以 AI 有相当大机会真正长出 taste（靠同样的「学习、吸收、打破模式」循环）；偏乐观、冲着「AI 不可能有 taste」一派，本身是观点。可检验关口是 AI 能否引入真正变化而非过拟合训练分布（[2026-06-27-nikunj-taste-iteration-ai]，同场讨论另一面见 [2026-06-18-zara-zhang-taste-before-ai-writing]）

### 其他赛道/趋势判断
- 网络安全看多：攻击节奏随模型能力提升加快、人仍是首要攻击向量；发在 Vercel 入侵通报后不到一小时，VC 观点帖无数据支撑（[2026-04-20-cybersecurity-thesis]）
- DoorDash 式选址：更多资深创业者会在 Palo Alto 这类大城市旁的郊区建公司；自称 SF-pilled，此条是对 SF 中心论的局部修正（[2026-04-13-nikunj-doordash-strategy]）

### 写作与社区
- 好写作 = 简洁清晰地传达问题关键 + 留一条在发酵的线；自己会因思路混乱几周不公开写作（[2026-04-26-nikunj-clear-writing]）
- 发起 ex-founder 社区 Dawn：创业每个阶段都有社区，公司之后的阶段没有；首场闭门晚宴 5 月 19 日旧金山（[2026-04-28-dawn-exfounder-community]）
