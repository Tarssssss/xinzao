# Ryo Lu（Cursor 设计师，前 Notion、Stripe）

Cursor 设计师，刊中主线是 AI 时代的产品设计方法论：批判 overcooking（合理决定堆积出混乱）、主张 opinionated design（无观点本身是强观点）；另有一条带自家产品宣传成分的工具切换。两条设计长文立场一致互补，无立场变化。

## 立场与主张

**Overcooking：AI 放大的设计失败模式**
- 定义：一堆没人说不的合理决定累积出的结果——每个决定单独看都说得通，堆在一起焦点全无（2026-04-23-overcooking）
- AI 放大机制：加东西的成本压到近零，几分钟造一个功能，人们不停地加；根子是多数「新想法」不新，只是旧概念换皮，思考没变深（同上）
- 解法：完整的东西有一个核，要看穿混乱、回到这个东西本来是什么、砍掉一切不服务于它的部分——这件事现在更难，因为永远还有一个 prompt 就能加上的东西；AI 之后做出来不再稀缺，质量分水岭移到愿不愿收敛打磨（同上，与 Peter Yang「craft 在最后 10%」同日呼应）

**Opinionated design：通用性来自强观点**
- 反对把 opinionated 和通用当对立面：决定系统里存在哪些概念、什么可见什么隐藏，本身就是表达世界观，「无观点」本身是强观点（2026-05-01-ryo-lu-opinionated-design）
- 批评纯客户导向：用户反馈指出摩擦在哪，很少指出系统该是什么；只跟直接需求走会收敛到局部最优——碎片化功能、窄工具（同上）
- 方法论：先把概念削减到本质、直到 primitives 清晰，再为每个概念修出延展组合的路径；灵活性是一组凝聚强观点的产物。收尾句：「核心处简单，边缘处开放。这是终极的观点。」（同上）

**工具实践（带自家宣传成分）**
- 日常主力完全切到 GPT-5.5 + Composer 2，称「智能、速度和成本的完美组合」「只在 Cursor 里有」，发在 GPT-5.5 开放 API 几小时后；/multitask 可跳出任务队列并行干活（2026-04-25-ryolu-cursor-switch）
- 校准：他是 Cursor 员工，「完美组合」按营销话术打折听；可核验的是 GPT-5.5 已在 Cursor 可用、他本人换了主力（同上）
