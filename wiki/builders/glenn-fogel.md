# Glenn Fogel（CEO @ Booking Holdings）

旅行业在位者，二十七年任期内亲历 Priceline 从几亿到千亿美元市值。刊中首次出现，来自 No Priors 播客一手访谈：既讲 Penny（Priceline 的 agent 旅行顾问）的采用情况，也坦承企业侧对 agent 经济账的认知仍不完整。立场提示：他是这门生意的经营者，「没有护城河」和「不要读太多单条新闻」这类表态服务于稳定市场预期。

## 立场与主张

- **Penny 的实际情况**：据主持人转述，团队此前透露采用率连续数月翻倍；但 Fogel 自己补充，公司还没有算清每次调用的真实 token 成本、也没有对应出长期客户价值和留存率的变化——这是规模化部署之后仍未解的问题，不是营销话术（2026-07-12-fogel-booking-penny-agent-economics）。
- **token 路由是开放问题**：明确说「该用哪个模型、什么时候用」本身还在摸索，不同模型的 token 便宜程度差很多——传统企业侧的多模型成本判断，和 Levie 反复讲的路由难题是同一件事。
- **规模仍小**：去年 Booking 交易额 1,860 亿美元、超十亿间夜，Penny 现在的用量占比可以忽略——不因为一个好用例就高估整体渗透率。
- **没有护城河**：反复重申的核心信念，认为唯一的活法是不停做新东西；这句话来自在位者本人，天然有为自己抗打击力辩护的动机。
- **对单条新闻保持怀疑**：OpenAI 一度上线又撤下 ChatGPT 旅行结账功能，Booking 股价先跌后涨约 8%，他的态度是两头都不要读太多。
