# Unsupervised Learning（播客渠道页）

Redpoint 投资人 Jacob Efron 主持的 AI 播客，「AI vibe check」圆桌是招牌格式：常邀 Datalogy 创始人 Ari（前 DeepMind/Meta 研究员，构建侧视角）与 Radical 的 Rob（VC，行业格局视角）。本页登记该渠道转述进日刊的判断。嘉宾非刊中常驻 builder，立场各带其位置（建模型 / 投资），引用时按位置打折。

## 核心判断（按主题）

### 算力紧缺重塑供给（2026-06）
- **API 供给风险**：实验室赚自家产品（Claude Code）多于赚 API，算力紧到一定程度可能限流甚至阶段性停掉公开 API——不是商业决策、是被算力逼的；OpenAI 卖「锁未来 token 额度」期货是前兆，Rob 说最强模型或只留内部用。Ari 预测 2027 年底前有把握看到 Anthropic 或 OpenAI 暂停/大幅限制 API 一段时间（带对冲）（[2026-06-13-compute-crunch-api-access-risk]）
- **开源退潮**：近前沿开源权重模型可能整体退场，能力其实在收敛、变的是经济账；Meta 在收、中国实验室把最强的留作闭源只开放更小版本；唯一可能跑通的开源生意是「开权重、不开 harness，用 API 卖整套系统」（Kimi/Moonshot 路子，API 已到几亿美元 ARR 量级）（[2026-06-13-open-weight-ai-decline]）
- **缓解时点**：两条的共同背景——真正缓解约 2030 前后，造芯/光刻突破至少五年外，所以是结构性挤压而非一阵子

### AI 先驱 Schmidhuber：看好技术、看衰模型公司（2026-07，Ep 90）
- **模型公司难赚钱**：Jürgen Schmidhuber 看好 AI 技术本身、深度看空做模型的公司。两条机制：开源只落后前沿三到六个月、闭源每破纪录后不久被追平，定价被压到举债建的数据中心「当下并不盈利」；递归自我改进的关键想法多出自小型学术实验室和开源社区（「大家用同一锅水做饭」），大公司守不住领先。据此判断当前 CapEx「严重过头」、押注「还不够快的算力」会反噬（[2026-07-19-schmidhuber-bearish-model-companies]）
- **与本页 6-13 判断的张力**：该期两位 VC 嘉宾判断近前沿开源模型会「退潮」（经济账不支持）；Schmidhuber 反过来把开源紧追当成压垮闭源定价的主力。两说都认为闭源溢价难持久，分歧在开源本身的命运。属长期看空者的学界立场，可核验的是「开源追平压定价」这条机制。
