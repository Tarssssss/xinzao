## 核心判断（按主题）

### 算力紧缺重塑供给（2026-06）
- **API 供给风险**：实验室赚自家产品（Claude Code）多于赚 API，算力紧到一定程度可能限流甚至阶段性停掉公开 API——不是商业决策、是被算力逼的；OpenAI 卖「锁未来 token 额度」期货是前兆，Rob 说最强模型或只留内部用。Ari 预测 2027 年底前有把握看到 Anthropic 或 OpenAI 暂停/大幅限制 API 一段时间（带对冲）（[2026-06-13-compute-crunch-api-access-risk]）
- **开源退潮**：近前沿开源权重模型可能整体退场，能力其实在收敛、变的是经济账；Meta 在收、中国实验室把最强的留作闭源只开放更小版本；唯一可能跑通的开源生意是「开权重、不开 harness，用 API 卖整套系统」（Kimi/Moonshot 路子，API 已到几亿美元 ARR 量级）（[2026-06-13-open-weight-ai-decline]）
- **缓解时点**：两条的共同背景——真正缓解约 2030 前后，造芯/光刻突破至少五年外，所以是结构性挤压而非一阵子
