# Sam Altman（OpenAI CEO）

OpenAI CEO，刊中言论集中在 Codex 增长与产品升级、算力供给判断、微软合作三条线，多为官宣口径，需与利益立场分开看。7 月起新增两类素材：对 AI 就业影响的个人判断转向承认，以及转发对自家模型不利的第三方数据而非反驳。

## 立场与主张

- **Codex 增长与运营**：把用户增长当公开里程碑运营——300 万周活时重置全员用量额度，并承诺每增长一百万再重置一次直到一千万（2026-04-08-codex-3m-reset）。
- **Computer use / agent 能力**：对 Codex 的 computer use 评价为「比他自己预期的更有用」，核心能力是并行操作 Mac 全部应用且不干扰用户当前操作（2026-04-17-codex-computer-use）。注意他是供给方，可核验点在行为本身（并行、不抢占窗口）。
- **算力供给**：判断随模型变强，世界会有一段时间处于算力受限。据此推「用 1-3 年用量承诺换折扣 token」的双向锁定，并向当批 YC 每家投 200 万美元 token（tokenmaxxing）；明确限定额度卖完即止、优先保 ChatGPT/Codex 容量，「双赢」是 hopefully 级措辞而非承诺（2026-05-20-sam-altman-discounted-token-commits）。
- **微软与云策略**：解除云独占，OpenAI 产品可上所有云，但微软仍是首要云伙伴，供应模型至 2032 年、收入分成至 2030 年；落地节奏与微软侧口径未披露（2026-04-28-openai-microsoft-clouds）。
- **就业判断（新，2026-07-12）**：承认「目前来看」AI 净创造就业，明说这和他自己此前的预期相反，且只把「这个方向可能继续」表述为可能性而非预测——这是他在刊中首次就 AI 就业影响给出个人判断，此前素材里没有类似表态（2026-07-12-altman-levie-swyx-ai-job-creation）。
- **对不利数据的态度（新，2026-07-12）**：转发 Dax Raad「团队 30% 成本花在 Fable 上」的截图并追问，没有反驳或删除——这条数据对 Sol 不算好消息，他选择放大而非压下（2026-07-12-dax-altman-fable-cost-share）。
- **容量扩张的坦白（新，2026-07-15）**：GPT-5.6 Sol 增长「快到离谱」，推理团队做了「英雄级」工作才撑住需求，但明说接下来「可能会出点小状况」——与团队同日讨论「用量逼近 900 万、要不要再重置额度」呼应，是少见的把扩容压力主动说出口而非等出问题再解释（2026-07-15-codex-chatgpt-work-9m-reset）。
- 除上述三条新表态外，其余素材内无立场反转。
