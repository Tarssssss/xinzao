# Sam Altman（OpenAI CEO）

OpenAI CEO，刊中言论集中在 Codex 增长与产品升级、算力供给判断、微软合作三条线，多为官宣口径，需与利益立场分开看。

## 立场与主张

- **Codex 增长与运营**：把用户增长当公开里程碑运营——300 万周活时重置全员用量额度，并承诺每增长一百万再重置一次直到一千万（2026-04-08-codex-3m-reset）。
- **Computer use / agent 能力**：对 Codex 的 computer use 评价为「比他自己预期的更有用」，核心能力是并行操作 Mac 全部应用且不干扰用户当前操作（2026-04-17-codex-computer-use）。注意他是供给方，可核验点在行为本身（并行、不抢占窗口）。
- **算力供给**：判断随模型变强，世界会有一段时间处于算力受限。据此推「用 1-3 年用量承诺换折扣 token」的双向锁定，并向当批 YC 每家投 200 万美元 token（tokenmaxxing）；明确限定额度卖完即止、优先保 ChatGPT/Codex 容量，「双赢」是 hopefully 级措辞而非承诺（2026-05-20-sam-altman-discounted-token-commits）。
- **微软与云策略**：解除云独占，OpenAI 产品可上所有云，但微软仍是首要云伙伴，供应模型至 2032 年、收入分成至 2030 年；落地节奏与微软侧口径未披露（2026-04-28-openai-microsoft-clouds）。
- 截至目前素材内无立场反转。
