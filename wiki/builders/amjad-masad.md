# Amjad Masad（Replit CEO）

爱做大胆的方向性断言：核心关注是 AI/bot 大规模进入生产后，安全与基础设施经济学会被重写。

## 立场与主张

- **安全成为默认要求**：断代式判断「2025 年起每家公司都是网络安全公司」（一句话推文、无论据）（2026-04-26-amasad-cybersecurity）。更具体的提议：前沿模型把找漏洞完全自动化后，GitHub 应在 star 旁加「加固算力投入」指标，称这是开源软件能被信任的唯一办法（2026-04-16-amjad-oss-security-metric）。两条同向：把安全投入推成公开、可比的信号。
- **bot 流量与免费层经济学**：human-level bot 出现后免费服务难以为继；值得探索微支付（每次 git push 收几美分），结算或可用比特币以保持开放、免 KYC。措辞停在「值得探索」，非 Replit 产品动作，但 Replit 作为开发者平台对 bot 流量成本有直接体感（2026-04-29-micropayments-for-git-push）。

证据等级普遍偏低（推文级断言、提议），价值在方向信号而非论证。暂无立场变化。
