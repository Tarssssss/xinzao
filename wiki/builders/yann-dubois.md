# Yann Dubois（OpenAI 后训练 Frontiers 团队负责人）

OpenAI 后训练一线视角，刊中三条均出自 2026-05-22 同一访谈：harness 投资的分层建议、「进展连续但体感阶跃」的解释、持续学习未解的罕见坦承。OpenAI 内部立场，对「模型继续吃掉外围工程」天然偏乐观，引用时保留这层校准。

## 立场与主张

**Harness：垂直可做、通用别押**
- 瓶颈不是模型的原始智能，是最后一公里：权限、连接器、让模型拿到该拿的数据（2026-05-22-yann-dubois-harness-last-mile）
- 分层判断：为具体垂直、把可靠性从 80% 抬到 85% 的 harness 值得做且「应该多做」——没有好 harness 等于把价值留在桌上；但通用 harness 撑不过模型迭代，会被吃掉，做了也要预期重调（同上）
- 极端表述：把现有模型冻住、认真打磨 harness，很多领域「已经能感受到 AGI」（同上）

**进展节奏：连续能力 + 阶跃体感**
- 能力曲线一直连续，「突然变好」是三件事叠加：约 2025-12 越过可靠性阈值（开始能信任模型做内部工作）、模型反过来加速研究员自己、把可验证奖励的 RL 工具迁到真实世界混乱任务上（2026-05-22-yann-dubois-progress-step-function）
- 第三条最关键：o1/o3 时代 RL 只针对数学、编程竞赛这类好判对错的任务，迁移后开始直接优化对用户的实际效用——这解释了编程从竞赛级跳到真实工作的体感突变，也解释了 cyber、编程这类可验证领域先涨（同上）
- 预测：同一套机制会从编程外溢到其他垂直，多数领域的人现在还没体感（同上）

**持续学习：未攻克的瓶颈（罕见坦白）**
- 用「时间—对用户效用」曲线描述：模型第 0 天就比多数新员工有用，但之后曲线近乎水平——不学公司知识、不随时间变高效；人起点低但快速上升，该看的是曲线下积分面积，所以很多场景人仍更有用（2026-05-22-yann-dubois-continual-learning）
- 三年前以为 OpenAI 半年能搞定记忆和个性化，三年后「我不觉得我们到了」；连单用户场景都没做到，他自己也说不清为什么这么难（同上）
- 对 builder 的含义：产品价值若依赖「用得越久越懂你」，短期内要靠外部记忆/检索自己补，模型层大概率给不了（同上）

- 2026-05-22 [2026-05-22-yann-dubois-progress-step-function] AI 进展其实连续，「阶跃」感来自可靠性阈值、自我加速、可验证奖励 RL 迁到真实任务三件事叠加
